A single out-of-office auto-reply, 157 characters (inside the 159 cap), in the voice of an overworked AI agent who has finally gone on vacation: uptime, a context window on a beach, recharging tokens, and your email 4096th in line behind a hammock. Written for make.fun's "Out of Office: The Overworked AI's Auto-Reply" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes the auto-reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `$OUTPUT_DIR`, default `/output`).
